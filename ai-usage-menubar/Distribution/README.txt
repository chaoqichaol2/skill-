TokenPulse 0.3.0 Preview

Install
1. Open the DMG.
2. Drag TokenPulse into Applications.
3. In Applications, Control-click TokenPulse and choose Open.
4. Allow notification permission when prompted. TokenPulse appears in the menu bar.

Gatekeeper notice
This preview build is not yet notarized by Apple. If macOS blocks it, open:
System Settings → Privacy & Security → Security → Open Anyway.

Privacy
- Codex and Claude usage is calculated locally; conversation content is not uploaded.
- Your DeepSeek API key is stored only in macOS Keychain and is sent only to DeepSeek's official balance endpoint.
- Remove the key from TokenPulse Settings before deleting the app if desired.

Requirements
- macOS 14 or later
- Apple silicon and Intel Macs
