# 豆包水印清理室

这是一个离线运行的本地网页应用。图片不会上传到互联网，原图不会被覆盖。

## macOS 使用方法

1. 双击 `启动.command`。
2. 首次运行会安装约 70 MB 的处理组件，安装完成后自动打开浏览器。
3. 导入图片，保持“豆包自动”，点击“开始清除水印”。
4. 如果水印位置不是常见的右下角，切换“手动框选”，在图片上框住水印后处理。
5. 检查处理后图片并下载。

以后再次使用只需双击 `启动.command`，不需要重复安装。

## Windows 使用方法

1. 双击 `启动.bat`。
2. 首次运行会安装处理组件，完成后自动打开浏览器。
3. 后续操作与 macOS 相同。

## 系统要求

- macOS 11 或更高版本，或 Windows 10/11。
- Python 3.10–3.13。若电脑没有 Python，可从 <https://www.python.org/downloads/> 安装。
- 首次安装需要联网，日常处理可断网运行。

## 当前能力

- 自动清除常见右下角“豆包”可见水印。
- 手动画框清除任意小面积角标或文字水印。
- 支持 PNG、JPG/JPEG、WebP，单张最大 50 MB。
- 使用 OpenCV 局部修复，速度快、无需显卡和大模型。

## 注意事项

- 复杂纹理、人物五官、细小文字等区域可能需要多次框选或更高质量的 AI 修复模型。
- 只处理你拥有版权或已获授权编辑的图片。
- 本项目只处理可见水印，不移除隐形水印、内容凭证或来源信息。
